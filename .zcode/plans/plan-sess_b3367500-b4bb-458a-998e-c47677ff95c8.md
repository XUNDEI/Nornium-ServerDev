# 给编辑器前端添加「服务器控制台」（实时日志 + 指令输入）

## 现状结论
- 编辑器前端（`server/editor/index.html + style.css + app.js`）已有「服务器管理」工作区（`#navServer`），加一个「控制台」标签页即可自然融入。
- 服务端日志统一走 `server/src/logger.js`（stdout + `logs/server.log`），另有少量裸 `console.log`（启动横幅、控制台 REPL 回显）——目前没有任何推送给前端的机制，也没有 WebSocket/SSE。
- 网页指令可完整复用 `src/console.js` 已导出的 `handleCommand(line, hooks)`（restore/load/export/allweapons/stop/status/help），危险操作自动经 `hooks.maintenance` 维护窗口（index.js 注入），与黑窗口行为完全一致。

## 后端改动

### 1. `server/src/logger.js` — 日志缓冲 + 订阅（唯一捕获点）
- 进程内维护环形缓冲（约 2000 行），每行 `{ seq, text }`（seq 单调递增）。
- 包装 `console.log/warn/error`：裸 console 输出（启动横幅、REPL 回显）也进缓冲；`write()` 改为直接调原始 console 引用并自行入队一次，避免双重捕获。
- 导出 `tail(after)` → `{ lines, last }`（seq > after 的行，最多回 500 行）与 `subscribe(fn)` → 退订函数（供 SSE 用）。

### 2. `server/src/editorapi.js` — 三个接口
- `GET /editor/api/console/tail?after=N`：JSON 信封 `{ lines, last }`，供页面打开时先拉历史。
- `GET /editor/api/console/stream`：SSE。先回缓冲里 `?after=N` 之后的行，再实时推送；`retry:` + 每 15s 心跳注释保活；`req.close` 时退订。在 `handle()` 里、JSON 信封解析之前单独分支处理（不是 JSON 响应）。
- `POST /editor/api/console/cmd`：body `{ command }` → 调 `console.handleCommand(command, hooks)`，返回 `{ reply, action }`。reply 同时 `console.log` 到黑窗口，两个入口互通可见；`action === 'stop'` 时复用现有停服模式（先回响应，`finish` 后延迟 150ms 调 `hooks.onStop`）。

## 前端改动

### 3. `server/editor/index.html`
- `#navServer` 加「控制台」标签页（`data-tab="console"`，终端图标）。
- 帮助弹窗第 2 节补一句控制台说明。

### 4. `server/editor/app.js`
- `TABS` 加 `console` 条目；`ICONS` 加终端图标；`renderTab` 渲染表加 `renderConsole`。
- `renderConsole(el)`：
  - 工具栏：「自动滚动」开关（用户上滚自动取消勾选）、清屏（仅客户端）、行数提示。
  - 等宽日志视图（`--mono`，按级别着色：`[E]` 强调、`[W]` 次强调、`[V]` 淡化；HTML 转义）。打开时先 `tail` 拉历史，再开 `EventSource('/editor/api/console/stream?after=N')` 实时追加；客户端只保留最近约 2000 行。
  - 指令输入行：输入框 + 发送按钮，回车发送；↑/↓ 翻本地指令历史。restore/stop 及 load/export 走现有 `askConfirm` 确认弹窗（restore 要求输入「清空存档」确认词，与服务器管理页同口径）。
  - 生命周期：离开控制台页或 `markStopped()` 时关闭 EventSource；响应 `action === 'stop'` 时调用现有 `markStopped()` 走停服遮罩流程。

### 5. `server/editor/style.css`
- 新增 `.console-view` / `.console-line`（含 i/w/e/v 四个级别类）/ `.console-input` 样式，全部走现有主题 token 与等宽字体变量，保持扁平黑白语言。
