修复「远航支援商店」购买报错 cmd:302 code:1

## 根因（已定位）
- `cmd:302` = `res_player_universe_growth`，`code:1` = `MAX_RANK`。
- 服务端把它实现成了**无条件返回 MAX_RANK 的桩**：`server/src/handlers/universe.js:860-862`，注册于 :889。重置接口也是空应答：`server/src/handlers/social.js:454`。
- 客户端逻辑（权威）：`reference/client_lua/Module/Player/PlayerSystem.lua:58-129` —— 远航点数 = `GetSrpgGrowthLevel() − Σ(d_srpg_growth[id].cost × node_rank)`；远航等级 = 背包中 **id 9003** 道具数量当经验，查 `d_srpg_exp` 累计得出。点数**不从背包扣除**（9003 是永久经验型货币，花费是虚拟记账，存在 node_rank 里）。
- 数据表齐全：`reference/gamedata/d_srpg_growth.json`（8 节点：1=建筑蓝图+1[effectType 11→卡池100]、2=金刚凝胶[effectType 1]、4=生存值[effectType 2]、5/6/7/8/9=战斗属性[type 2, effectType 0]）、`d_srpg_exp.json`。玩家存档字段 `player_universe_growth_node_infos` 已在 `game/player_new.js:89` 初始化并随 res_player 下发，新号已发 999 个 9003。

## 改动

### 1. 实现购买：`server/src/handlers/universe.js`
替换 :860 的桩为真实 handler：
- 辅助函数（放同文件或 `game/` 下）：`growthLevel(player)`（`bagCount(player,9003)`（`game/items.js:96`）→ 逐行消耗 `d_srpg_exp`，与客户端 `GetSrpgGrowthLevel` 同语义）、`spentGrowthPoints(player)`、`growthNodeRank(player, nodeId)`。
- handler：查 `d_srpg_growth[node_id]`（gd.query，注意 String 键）；无此行 → 回 1（防御）；
  - `node_rank >= cfg.level` → 回 `MAX_RANK(1)`；
  - 剩余点数 < `cfg.cost` → 回 `RES_NOT_ENOUGH(2)`；
  - 否则 upsert `{node_id, node_rank+1}` 到 `player.player.player_universe_growth_node_infos`，`savePlayer`，回 `{}`（OK）。
- 不动背包：客户端 result=0 时自己本地 +1 并刷新 UI（`UI_SRPG_GrowthShop_C.lua:147-156`），应答只需空 body。

### 2. 实现重置：`server/src/handlers/social.js:454`
清空 `player_universe_growth_node_infos` + `savePlayer` + 回空应答（清空即自动退点，点数=等级−已花费）。

### 3. 增益接入开局：`server/src/game/universe.js` `newUniverse()`（:129，初始值在 :188/:191）
按玩家已购节点等级在开局生效（type 1 节点）：
- **effectType 1（节点2 金刚凝胶）**：按 rank 取 `effectDisplay{rank}`（如 [0,50,0,0]）加进 `res_value` 对应位；
- **effectType 2（节点4 生存值）**：`effectDisplay{rank}`（[1]/[2]/[3]）加到 `cur_hp`；
- **节点1 建筑蓝图 +1**：每级从卡池 100（`d_srpg_card_pool` 行 100，复用 handlers/universe.js 中 effectType 11 的池展开逻辑，必要时抽成共享 helper）随机 1 张蓝图直接进开局手牌 `u.cards`；
- type 2 战斗属性节点（5/6/7/8/9，effectType 0）：全客户端 grep 无任何消费点（只有商店/总览 UI 读它），客户端本地也不结算，**不接入**，在文档中记录。
