使用说明

1. 改动的生效方式

  • 所有编辑先进入右上角待保存清单，点「保存修改」才写入。
  • 目标玩家在线时服务端直接改内存并推送通知，游戏内立刻生效，不用重登。
  • 玩家离线时写盘保存，重新登录后生效。
  • 切换存档前请先保存或清空清单，避免改动丢失。

2. 三个工作区

  • 左栏顶部可以切换存档管理、服务器管理与游戏启动器，三块互不依赖：后两者不需要先选中存档。
  • 存档管理：总览（昵称/货币）、背包、角色（含星位/命座）、抽卡、商城、剧情，以及存档备份（导出/快照）。
  • 服务器管理：服务端状态、立即备份、踢人、导入、清档、停服，以及实时日志控制台（可直接执行 load / export 等指令）。
  • 游戏启动器：一键经 Steam 拉起游戏、查看游戏目录与补丁状态；Mod 管理页负责导入、启用排序、冲突报告， 并把启用中的 mod 合并打包成单个补丁 pak 装进游戏（详见项目 docs/MOD_FORMAT.md）。
  • 主页（未选存档时）优先显示服务器状态，下面才是选档引导。
  • 没选存档时右侧的存档页标签是禁用的（灰掉、鼠标悬停有提示），其余工作区不受影响。

3. 等级与经验

  • 改「等级」会按数据表自动换算经验；手改「经验」则以经验为准。
  • 等级上限由突破次数决定（0/1/2/3/4/5 → 20/40/50/60/70/80）。

4. 为什么有些武器不能发

  • 标着未实装的武器在客户端没有模型、图标与技能行，发下去会让武器详情面板出错，所以编辑器拒绝发放。
  • 「专武」是每名可玩角色的 7★ 专属武器（官方数据映射，角色弹窗里写明名字与 6★ 基础形态； 两形态数值完全相同，7★ 是最终形态）。只要全部武器就用「发放全部高稀有度武器」。

5. 角色精细化编辑

  • 点角色卡片打开弹窗后：逐孔勾选星位（带「全选 / 只留初始孔」，悬停可看孔位与条件）、 逐件勾选皮肤并指定穿戴（战斗 / 机甲 / 主城三类）、逐个技能改等级、 给六个部位换装或卸下机甲（卸下的会回到背包）。
  • 这些改动同样先进「待保存清单」，按你勾选的精确清单提交（不是「全部解锁」那种粗粒度开关）。

6. 服务器控制台

  • 输入框支持 Tab 自动补全（指令名 / 账号 / 快照目录 / 角色 id）， ↑↓ 在候选面板里移动（没开面板时是翻历史），回车执行。
  • 输出按级别着色：普通 / 调试 / 警告 / 错误 / «指令回显»， 底部有图例；危险指令执行前会弹确认框。

7. 危险操作

  • 危险区域与危险按钮都用红色标出（清空存档、停止服务端、清空月卡、背包行内删除）。
  • 清空存档需要手动输入确认文字，停止服务端点击确认即可；清档前会自动留一份 data_wipe_* 快照。

8. 快捷键

  • Ctrl/Cmd + S 保存修改 · / 聚焦搜索框 · Esc 关闭弹窗/抽屉

9. 项目主页

  • 本服务端是开源项目：github.com/XUNDEI/Nornium-ServerDev
  • 它是完全免费的；遇到报错、想反馈或想拿新版，都先看这个页面（侧栏底部也有入口）。
